# Course materials

Open, self-paced curriculum for **AI-Powered Inventor**. You do **not** need Cursor or any special IDE. Use:

1. These markdown files
2. An LLM of your choice (ChatGPT, Claude, local model, etc.)
3. A text editor for artifacts (`requirements.md`, `design.json`, …)

## Start

1. Read [`start-here.md`](start-here.md) or the [course home](index.md)
2. Open Track A: [`track-a/overview.md`](track-a/overview.md)
3. Work exercises in order under [`track-a/exercises/`](track-a/exercises/)
4. Load the agent pack when an exercise says to: [`track-a/agents/circuit-lite/`](track-a/agents/circuit-lite/)

## How to use an agent pack

1. Open `SYSTEM.md` — paste it as the **system** (or custom instructions) prompt in your LLM.
2. Keep `TOOLS.md` and `WORKFLOW.md` in context (paste or attach).
3. Put your working files in a copy of [`track-a/templates/`](track-a/templates/) (do not overwrite the blanks if you want a clean restart).
