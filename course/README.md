# Course materials

Open, self-paced curriculum for **AI-Powered Inventor**. You do **not** need Cursor or any special IDE. Use:

1. These markdown files
2. An LLM of your choice (ChatGPT, Claude, local model, etc.)
3. A text editor for artifacts (`requirements.md`, `design.json`, …)

## Start

1. Open the [course home](index.md) or [week list](weeks/index.md)
2. Begin [Week 1 — Agentic foundations](weeks/01-foundations.md)
3. Load the agent pack when the week says to: [`agents/circuit-lite/`](agents/circuit-lite/)

## How to use an agent pack

1. Open `SYSTEM.md` — paste it as the **system** (or custom instructions) prompt in your LLM.
2. Keep `TOOLS.md` and `WORKFLOW.md` in context (paste or attach).
3. Put your working files in a copy of [`templates/`](templates/) (do not overwrite the blanks if you want a clean restart).
