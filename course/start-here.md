# Start here — Track A gateway

Welcome. This gateway builds a mental model of **models, assistants, agents, harnesses, and engineering workflows**, then applies it to a small piece of a real product: the **Environmental Monitor** analog front-end.

This course is **open and self-paced**. Work through phases in order; you own timing and review.

## What you will do

1. Contrast a raw LLM answer with a tool-using agent loop.
2. Follow a harness-style workflow (plan → act → observe → validate).
3. Pass a deterministic checklist (`Gate_Circuit_lite`) without rewriting the math by hand for the agent.
4. Practice a **human review** gate before anything is marked released.

## What you need

- An LLM you can paste a system prompt into
- A text editor
- About half a day of focused work
