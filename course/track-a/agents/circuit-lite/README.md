# Agent pack — circuit-lite

Portable agent for Track A Environmental Monitor **signal conditioning** (resistor divider / front-end math).

**Not Cursor-specific.** Paste these files into any LLM that supports a system prompt.

| File | Use |
|------|-----|
| [`SYSTEM.md`](SYSTEM.md) | System / custom instructions |
| [`TOOLS.md`](TOOLS.md) | Allow-listed tools (you or a future harness execute them) |
| [`WORKFLOW.md`](WORKFLOW.md) | Plan → act → observe → validate → human review |

Load all three before asking for a design. Stay inside the tool allow-list.
