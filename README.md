# AI-Powered Inventor — curriculum

**A1 Workshop** (`a1-workshop`) public repo **`a1-inventor`**: full instructor/admin source for the AI-Powered Inventor program (agentic engineering harnesses; Environmental Monitor through-line: circuit → PCB → enclosure → system).

Delivered **in partnership with Humanmade**. Org and repo map: [`docs/org.md`](docs/org.md).

License: [MIT](LICENSE). Contributing: [`CONTRIBUTING.md`](CONTRIBUTING.md).

## Public repo, spoiler contract

Repos are public. The learning boundary is **what students open**, not GitHub private mode.

- **Students:** use only [`student/`](student/) (and docs/workflow links from there). Do **not** open answer keys under `instructor/`.
- **Future:** a sibling public repo **`a1-student`** will hold a curated extract without keys. Until then, stay in `student/`.

**Students do not need Cursor.** Use any LLM plus the agent packs under `student/`. Cursor is for workshop authors (`design/`).
