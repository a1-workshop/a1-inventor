# AI Driven Invention

**A1 Workshop** public repo **`a1-inventor`**: open, self-paced course on agentic engineering harnesses. Environmental Monitor through-line: circuit → PCB → enclosure → system.

**Live site:** [https://a1-workshop.github.io/a1-inventor/](https://a1-workshop.github.io/a1-inventor/)  
**Org hub:** [https://a1-workshop.github.io](https://a1-workshop.github.io)

License: [MIT](LICENSE). Contributing: [`CONTRIBUTING.md`](CONTRIBUTING.md). Authors/agents: [`AGENTS.md`](AGENTS.md).

## Open course

Everything under [`course/`](course/) is for learners. There is no separate instructor or answer-key tree. Use any LLM plus the agent packs; no special IDE required.

## Build the site

```bash
npm install
npm run dev    # local preview
npm run build  # site/_site/
```
