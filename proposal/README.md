## Locked for this draft

- Three-track ladder: A (1-day foundations) → B (4 weeks) → C (10 weeks)
- Environmental Monitor as the shared product through-line (circuit → PCB → enclosure → system)
- Hybrid delivery: instructor opens each phase; students run labs with their own LLM
- Deterministic validation gates + mandatory human review (engineer sign-off)
