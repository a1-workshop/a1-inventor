# Contributing

This repository is an **open course**. Improvements to `course/`, `workflow/`, and `site/` are welcome.

- Keep materials learner-facing. Do not reintroduce instructor-only or spoiler-gated trees.
- Curriculum SSOT is markdown under `course/`. The Eleventy site generates from it — do not hand-mirror lessons into HTML.
- Run `npm run build` before proposing site changes.
